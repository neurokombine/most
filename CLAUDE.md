# Мост — инструкции нейросети

> Мост связывает чат в Telegram и Max с нейросетью `claude -p` в папке проекта на сервере.
> Один процесс, два приёмника, одна папка состояния на экземпляр.
> Работай автономно: решай сам, по мелочам не спрашивай.

## 1 · Как устроено

```
Телефон (Telegram · Max)
   │ long polling: getUpdates / GET /updates
   ▼
bridge/receivers/*  → единый Incoming(channel, chat_id, user_id, text, thread_id, raw)
   ▼
bridge/router.py    → свой или чужой · команда словами · папка проекта
   ▼
bridge/executor.py  → claude -p в папке, чистое окружение, журнал работы папкой
   ▼
bridge/narrator.py  → stream-json → человеческий текст, разрезанный под лимит канала
   ▼
ответ в тот же канал, откуда пришёл вопрос
```

| Файл | За что отвечает |
|---|---|
| `bridge/__main__.py` | сборка по настройкам и запуск: `python -m bridge --name <экземпляр>` |
| `bridge/daemon.py` | цикл, три класса бед, коды выхода 0 и 3 |
| `bridge/config.py` | `~/.most/<имя>/config.yaml`, права на файл, секреты |
| `bridge/store.py` | SQLite (WAL): links · schedule · allowlist · settings · journal · jobs |
| `bridge/router.py` | список своих, журнал стуков, папки проектов, команды словами |
| `bridge/executor.py` | адаптер к нейросети: `ClaudeExecutor` и `FakeExecutor` |
| `bridge/narrator.py` | разбор stream-json и нарезка под 4096 (Telegram) и 4000 (Max) |
| `bridge/doctor.py` | самопроверка; полностью разворачивается на этапе 6 |
| `bridge/texts.py` | **все** тексты человеку, по-русски, в одном месте |

## 2 · Правила, которые нельзя нарушать

1. **Ключей API нейросетей в мосте нет ни в каком виде.** Исполнитель работает под
   сохранённым входом по подписке. Увидел `ANTHROPIC_API_KEY` в коде или в примере —
   это ошибка, а не оптимизация.
2. **Токен бота — только из файла с правами 600.** Никогда в argv: `ps` виден всем.
   Любой текст ошибки прогоняется через `mask()` до записи в лог и до отправки в чат.
3. **Чистое окружение для вложенного `claude`** (`clean_env()`). Без этого он наследует
   `CLAUDECODE` / `CLAUDE_CODE_ENTRYPOINT` и молча падает — грабля стоила отладки дважды.
4. **Пустой список своих = не отвечаем никому.** Чужой стук — молчание в чат и запись
   в журнал. Без записи молчание неотличимо от поломки.
5. **Три класса бед разведены по поведению, а не по номеру кода:** слушателя перехватили
   и токен не признан — гасим канал; «подождите» — ждём ровно столько, сколько сказали.
   Молчаливый вечный ретрай опаснее честной остановки.
6. **Состояние живёт на диске, не в памяти демона.** Смещение Telegram и marker Max —
   в `settings`, работа — папкой в `jobs/`. После перезагрузки мост не отвечает на вчерашнее.
7. **Латиница в путях и именах файлов, русский — в текстах человеку.** Кириллица в путях
   уже ломала живой прогон.
8. **Схему базы не урезаем.** Таблицы будущих этапов заведены сразу: миграция на
   ученической машине дороже пустых таблиц.

## 3 · Как менять код

Сначала тест, потом код. Тесты не ходят в сеть и не зовут настоящий `claude`:
приёмники — на подставном `requests` (`tests/fakes.py`), исполнитель — на `FakeExecutor`
и на скрипте-обманке вместо `claude`.

```bash
python -m pytest                      # всё
python -m pytest tests/test_router.py -q
```

Добавляешь текст человеку — клади его в `bridge/texts.py`, а не в код. Тон: тепло,
по делу, без жаргона и без восклицаний. На каждую беду — что случилось и что сделать
(«бот не заведён или токен перевыпущен — вернитесь к отцу ботов»).

## 4 · Что впереди по этапам

Спецификация — `ПЛАН-ТЕЛЕГРАМ-МОСТ.md` в папке курса, § 3.

| Этап | Что добавляет | Куда ляжет |
|---|---|---|
| 2 | продолжение сессии (`--resume`), очередь «одна связка — одна работа», «стоп» | `executor.py`, `router.py`, `links.state` |
| 3 | файлы: `входящие/` и `отдать/`, пределы 20 и 50 МБ | новый `postman.py`, `receivers/*` |
| 4 | голос: распознавание на самой машине, ответ выжимкой | новый `voice.py` |
| 5 | расписание и обязательный отчёт о прогоне | таблица `schedule`, новый `alarm.py` |
| 6 | доктор целиком: юнит, вебхук, диск, память, последние отказы | `doctor.py` |
| 7 | установка одним промтом | `scripts/`, промт для ученика |

Готовые крючки: `links.session_id` пишется с первого дня (этап 2 возьмёт его для
`--resume`), `links.state` уже переключается на время работы, таблица `schedule` ждёт
этапа 5, `jobs` пишется с первой задачи.

## 5 · Частые вопросы к себе

- **Добавляю новый мессенджер?** Наследуй `Receiver`, отдавай `Incoming`, подними те же
  три класса бед — роутер и рассказчик не изменятся.
- **Хочу ответить сразу во все каналы?** Этого пока нет нарочно: ответ уходит туда,
  откуда пришёл вопрос. Сводки во все каналы — этап 5.
- **Нужна миграция базы?** Сначала проверь, нельзя ли обойтись полем в `settings`.
