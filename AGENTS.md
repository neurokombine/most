# Мост — инструкции нейросети

Этот файл для Codex, Kimi Code и любых других нейросетей, которые читают `AGENTS.md`.

Правила у всех одни и живут в **`CLAUDE.md`** рядом. Откройте его целиком и работайте
по нему: устройство пакета, двенадцать правил, которые нельзя нарушать, порядок работы
с тестами и план следующих этапов.

Коротко, чтобы не ошибиться до чтения:

- ключей API нейросетей в мосте нет ни в каком виде — только вход по подписке;
- токен бота живёт в `~/.most/<имя>/config.yaml` с правами 600 и никогда не попадает
  в командную строку и в логи;
- сначала тест, потом код: `python -m pytest`, сеть тестам не нужна;
- тексты человеку — по-русски и в одном месте, `bridge/texts.py`;
- работа идёт своим потоком, а отвечает в чат главный цикл (`Bridge.deliver`):
  из потоков в мессенджер не пишем и базу из-под них не закрываем;
- мостом управляют командами из серверного окна — `python -m bridge --name <имя>
  knock | allow | deny | who | status | doctor | say` (см. README, раздел «Как
  управлять мостом из серверного окна»); они читают ту же базу, что и живой мост,
  замок не берут и бота у него не отбирают;
- номер ошибки человеку не показываем: ни «409», ни «exit code» — причина словами
  и действие. Это проверяет `tests/test_texts.py`.
