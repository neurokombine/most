# Мост

Ваша система живёт на сервере и работает, пока вы спите. Мост — это её телефонная
трубка: вы пишете в Telegram или в Max обычным сообщением, нейросеть в папке проекта
делает работу, ответ приходит туда же, откуда вы спросили.

**Что это даёт:** не нужно открывать ноутбук, подключаться к серверу и вспоминать команды.
Написали с телефона в очереди — получили ответ.

**Кому мост отвечает:** только вам. Пока в списке своих пусто, он молчит всем, включая вас.
Это не поломка, а защита: сервер с вашей подпиской не должен слушать посторонних.

---

## Что уже работает, а что впереди

Сейчас в мосте собран **скелет: живой разговор**.

**Работает:**

- два мессенджера в одном процессе — Telegram и Max; настраивать можно любой из двух
  или оба сразу, ответ всегда уходит в тот чат, откуда пришёл вопрос;
- список своих: чужому мост не отвечает, но записывает стук в журнал — спросите
  «кто стучался» и увидите время и id;
- папки проектов: «покажи проекты», «работаем с бухгалтерией» — и задача уходит в ту папку;
- журнал каждой работы на диске: задание, поток ответа, ошибки, код выхода;
- всё состояние в одном файле `most.db` — мост переживает перезагрузку сервера.

**Впереди, по этапам:** продолжение разговора («система помнит прошлый вопрос»), очередь
задач, файлы туда и обратно, голосовые, расписание («каждое утро в семь…»), доктор
с самодиагностикой и установка одним промтом.

## Как поставить

Скажите своей нейросети:

> Забери мост по ссылке `<адрес репозитория>`, положи ко мне в домашнюю папку и поставь.
> Сначала расскажи, что собираешься сделать, — потом делай.

Руками то же самое:

```bash
bash scripts/setup.sh                       # один раз; заведёт .venv и настройки
.venv/bin/python scripts/selftest.py        # проверить, всё ли на месте
.venv/bin/python -m bridge --name default   # запустить
```

Зависимостей две: `requests` и `pyyaml`. Ничего тяжёлого мост не ставит и в интернет
за своё имя не ходит.

## Настройки

Лежат в `~/.most/<имя экземпляра>/config.yaml`, права на файл — 600, потому что внутри токен.

```yaml
telegram:
  token: "1234567:ваш-токен-от-отца-ботов"
  allowlist: [123456789]       # ваш Telegram id

max:
  token: "токен-от-MasterBot"
  allowlist: [987654321]       # ваш Max user_id

projects_dir: "/home/anna/projects"
executor: claude
timeout_sec: 900
```

Любой из двух разделов можно удалить целиком — мост будет работать с одним мессенджером.
**Токен живёт только в этом файле.** В командной строке он не появляется никогда: команда
`ps` на сервере видна всем, кто на нём есть.

Где взять токен: в Telegram — у отца ботов, это `@BotFather`, команда `/newbot`.
В Max — у `@MasterBot`. Свой id мост подскажет сам: напишите ему, пока список своих
пуст, а потом спросите с другого аккаунта «кто стучался».

## Несколько человек на одной машине

Один экземпляр — один человек со своим ботом и своей папкой проектов:

```bash
bash scripts/setup.sh anna
sudo systemctl enable --now most@anna
```

Настройки экземпляра — `~/.most/anna/config.yaml`, база и журнал работ — там же.
Забрать доступ = остановить его экземпляр: `sudo systemctl disable --now most@anna`.

## Автозапуск

```bash
sudo cp systemd/most@.service /etc/systemd/system/
sudo systemctl enable --now most@default
journalctl -u most@default -f          # смотреть, что он говорит
```

В юните два неочевидных места, и оба нарочно. Код выхода 3 значит «мой код обновился» —
юнит поднимает новую версию и не считает это падением. Код 0 значит «дальше чинить руками»
(токен не признан, слушателя перехватили): перезапуск тут не помогает, а вечный респавн
прячет поломку — мост честно останавливается и пишет причину в журнал.

## Что сказать мосту

| Вы пишете | Что происходит |
|---|---|
| любую задачу словами | уходит нейросети в текущую папку проекта, ответ приходит в чат |
| «покажи проекты» | список папок, текущая помечена |
| «работаем с бухгалтерией» | переключает папку для этого чата |
| «кто стучался» | кто писал, не будучи в списке своих: время, канал, id, первые слова |
| «помощь» | короткая шпаргалка теми же словами |

## Где что лежит

```
~/.most/<имя>/config.yaml     токен и список своих (права 600)
~/.most/<имя>/most.db         связки, список своих, расписание, журнал — всё состояние
~/.most/<имя>/jobs/<id>/      журнал одной работы: prompt.md, out.jsonl, err.log,
                              exit.code, pid, meta.json
~/projects/<папка>/           рабочие папки; в них и работает нейросеть
```

Незаменим здесь один файл — `most.db`. Остальное ставится заново за пять минут.

## Чего мост не делает

- **не ходит в интернет за ключами и не хранит их.** Нейросеть работает под вашим
  сохранённым входом по подписке; ключей API в мосте нет ни в каком виде;
- **не отвечает незнакомым** — и это не настройка, а устройство;
- **пока не принимает голосовые и файлы** и пока не помнит прошлый вопрос: это
  следующие этапы, они уже расписаны;
- **не ставит себе расписание** — тоже впереди.

## Проверить себя

```bash
.venv/bin/python scripts/selftest.py --name default   # настройки, права, claude, сеть
python -m pytest                                      # тесты пакета, сеть не нужна
```
